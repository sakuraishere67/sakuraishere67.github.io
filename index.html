How to Install & Setup

Follow these step-by-step numbered instructions to install the extension on your browser.

1

Unzip the Download

Extract the downloaded ZIP archive (`mikeybox-toolkit.zip`) to a folder on your computer so browsers can read the manifest and source files.

2

Open Extensions Page

Navigate to `chrome://extensions` (or `edge://extensions`, `brave://extensions`) in your browser address bar.

3

Enable Developer Mode

Toggle the Developer mode switch in the top-right corner of the extensions page.

4

Load Unpacked Folder

Click Load unpacked and select the extracted folder containing `manifest.json`. You're all set!

Frequently Asked Questions

Q: Is this extension safe to use in my browser?

A: Yes! The extension runs completely locally in your browser, utilizing open-source manifest standards without tracking personal data or passwords.

Q: How do I switch between different Sakura themes?

A: Once installed, click the puzzle icon in your browser toolbar, pin the Mikeybox Custom Themes extension, and click it to open the theme selector popup.

Q: Does it work on Firefox or Safari?

A: Yes, it is based for all browsers! Firefox supports temporary add-ons via `about:debugging`, and Safari users can convert the extension package effortlessly.
